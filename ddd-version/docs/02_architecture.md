# 架構設計

## 系統架構圖
```
┌─────────────────────────────────────┐
│         Main Window (Pygame)        │
│  ┌─────────────┐  ┌──────────────┐ │
│  │ Product     │  │ Cart Panel   │ │
│  │ List Panel  │  │              │ │
│  └─────────────┘  └──────────────┘ │
└─────────────────────────────────────┘
↓                ↓
┌──────────────────────────────┐
│      Cart (核心邏輯)          │
│  ┌────────┐  ┌─────────────┐ │
│  │ items  │  │ applied_    │ │
│  │        │  │ discount    │ │
│  └────────┘  └─────────────┘ │
└──────────────────────────────┘
↓
┌──────────────────────────────┐
│    Shared Resources          │
│  • Product                   │
│  • CartItem                  │
│  • DiscountCode              │
└──────────────────────────────┘
```

## Cart 類別職責
1. **狀態管理**：維護購物車項目和折扣碼
2. **業務邏輯**：驗證數量、庫存、折扣規則
3. **計算服務**：總金額、折扣金額、最終金額

## 設計原則
- **單一職責**：Cart 只負責購物車邏輯
- **依賴注入**：接受 Product、DiscountCode 物件
- **封裝性**：內部狀態只能透過方法修改

## 與共用資源的整合
- Cart 使用 shared/models/ 的資料類別
- Cart 不依賴 UI（可獨立測試）
- UI 透過 Cart 的公開方法操作購物車
