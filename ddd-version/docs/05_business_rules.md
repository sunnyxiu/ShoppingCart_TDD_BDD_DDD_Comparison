# 業務規則

## 1. 數量限制規則

### BR-001: 商品數量範圍
- **規則**：單項商品數量必須在 1-99 之間
- **原因**：避免惡意下單、系統負載
- **驗證時機**：加入購物車、更新數量時
- **錯誤處理**：返回 False，不修改購物車

**測試案例**：
| 輸入數量 | 預期結果 | 原因 |
|---------|---------|------|
| 0       | ❌ False | 小於最小值 |
| 1       | ✅ True  | 合法 |
| 50      | ✅ True  | 合法 |
| 99      | ✅ True  | 合法 |
| 100     | ❌ False | 超過最大值 |

---

### BR-002: 庫存限制
- **規則**：購買數量不能超過商品庫存
- **驗證時機**：加入購物車、更新數量時
- **錯誤處理**：返回 False

**範例**：
```python
# 商品庫存 10 個
cart.add_item(product, 5)   # ✅ 成功
cart.add_item(product, 3)   # ✅ 成功，累加後 8 個
cart.add_item(product, 5)   # ❌ 失敗，累加後會超過庫存
```

## 2. 折扣碼規則

### BR-101: 折扣碼啟用狀態
- **規則**：只有 `is_active == True` 的折扣碼可以使用
- **錯誤訊息**：「折扣碼已停用」

### BR-102: 最低消費門檻
- **規則**：購物車總金額必須 >= `discount_code.min_amount`
- **計算基準**：使用原始總金額（未折扣前）
- **錯誤訊息**：「未達最低消費金額 {min_amount} 元」

**範例**：
```python
# SAVE100: 滿 1000 折 100
cart.add_item(iphone, 1)  # 總額 30000
cart.apply_discount(save100)  # ✅ 成功（30000 >= 1000）

cart.clear()
cart.add_item(airpods, 1)  # 總額 500
cart.apply_discount(save100)  # ❌ 失敗（500 < 1000）
```

## 3. 價格計算規則

### BR-201: 小計計算
小計 = 商品單價 × 數量

### BR-202: 總金額計算
總金額 = Σ(所有項目的小計)

### BR-203: 折扣計算

**固定金額折扣**：
折扣金額 = discount_code.value
最終金額 = max(0, 總金額 - 折扣金額)

**百分比折扣**：
折扣金額 = 總金額 × (discount_code.value / 100)
最終金額 = 總金額 × (100 - discount_code.value) / 100
最終金額 = max(0, 最終金額)

**四捨五入規則**：
- 最終金額四捨五入到整數
- 使用 Python 的 `round()` 函數

**範例**：
```python
# 總金額 1000，SALE10（10% off）
折扣金額 = 1000 × 10 / 100 = 100
最終金額 = 1000 - 100 = 900

# 總金額 1550，SALE10（10% off）
折扣金額 = 1550 × 10 / 100 = 155
最終金額 = 1550 - 155 = 1395
